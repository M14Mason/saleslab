# SalesLab

Practice sales calls out loud with AI buyers, then get graded by an AI coach.

**Live:** https://m14mason.github.io/saleslab/

## How it works

| Piece | How | Cost |
|---|---|---|
| Your voice to text | Browser speech recognition (Chrome, Edge, Safari) | Free |
| Buyer replies | Claude Sonnet 5.5 ("Smart", default) or Haiku 5.5 ("Fast"), streamed, no up-front thinking, with a running call memory | Your Claude key |
| Buyer voice | Gender-matched device voice (prefers natural/neural voices) or Kokoro natural voice, per-buyer pitch, adjustable depth | Free |
| Buyer faces | Avataaars illustrations (Pablo Stanley, free for commercial use) via DiceBear (MIT) | Free |
| Live coaching tips, talk ratio, filler words | Computed on your device | Free |
| Coaching report | Claude Sonnet 5.5 with structured JSON output, saved after first run | Your Claude key |
| Storage | This browser only (localStorage). Backup export/import in Settings | Free |
| Hosting | GitHub Pages | Free |

There is no server. Your Claude key is stored in your browser and sent only to `api.anthropic.com`. Audio is never recorded.

## Features
- 32 scenarios across 22 types (pen challenge, financial plan close, wealth management, insurance, real estate, car sales, door to door, retail, startups, cybersecurity, medical devices, recruiting, investor pitch, donor ask, churn save, angry customer, wedding venue, internship interview, brand deal, and more), each with a "Learn this field" guide, plus your own scenarios written by hand or generated by AI
- Easy, Medium, Hard (changes real buyer behavior), Practice vs Assessment mode, surprise objections, 2 and 5 minute time limits
- Continuous listening with an adjustable pause before your turn ends, a Send button, Re-record, Interrupt, Pause, Mute, typing fallback
- Mic test with live level meter, device picker, quiet/muted warnings
- Reports: 12 explained skill scores, top 3 fixes, "say this instead" lines linked to the transcript, objections, practice plan, delivery stats
- Dashboard: daily challenge, recommendation for your weakest skill, streak, level, weekly goal, trend chart, skill radar, 12 achievements
- History search and filters, export report (.md), download transcript, share summary, delete
- Light and dark themes, reduced motion, keyboard shortcuts (Space, M, P, Esc), installable on iPhone (Share > Add to Home Screen)
- Demo mode: scripted buyer and sample data, no key needed

## Develop
```bash
npm install
npm run dev          # http://localhost:5173
npm test             # unit + integration tests (no network, no cost)
npm run build        # type-check + production build
PAGES=1 npm run build && npm run e2e   # browser tests at desktop, tablet, phone sizes (needs Playwright Chromium)
```
Use the key `demo` (or "Try demo mode") to run everything with the mock AI.

Model, effort, token and timeout settings live in `CONFIG` in `src/lib/claude.ts`. Set `localStorage["saleslab.debug"]="1"` to see timing logs (never transcript text).

## Deploy
Pushing to `main` runs `.github/workflows/pages.yml`: install, test, build, publish to GitHub Pages. Repo Settings > Pages > Source must be "GitHub Actions".

## Known limits
- Speech recognition always uses the system default mic in Chrome and Safari; the device picker applies to the mic test and level meter.
- iPhone: the mic must be started by a tap on some iOS versions; the app falls back to "Tap Talk". No live level meter on iPhone (it can interfere with recognition).
- No sync between devices. Use Export/Import backup in Settings.
- Delivery analysis is transcript-based: it can't judge tone, pace, or volume.
- Audio replay isn't available because audio is never recorded (by design).
